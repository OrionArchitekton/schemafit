## Release title

schemafit v0.5.1: README refresh and ASCII-only human output

## Release body

A small release ahead of the Show HN post. No rule-pack changes.

### Changed
- Human-readable `lint` output uses a colon after the status
  (`[anthropic] FAIL: 2 error(s), 0 warning(s)`) instead of a long dash.
  JSON and SARIF output and exit codes are unchanged.

### Docs
- README: PyPI and GHCR install paths, a one-command `uvx` demo with real
  output, Action/pre-commit examples pinned to a real tag, and absolute links so
  the PyPI project page renders correctly.

Install: `pip install schemafit` or `uvx schemafit --help`.
Container: `docker run --rm ghcr.io/orionarchitekton/schemafit demo`.

## Commands (for Dan, after the PR merges)

Tagging is the publish gate: the `v*` tag triggers `.github/workflows/release.yml`,
which publishes to PyPI (Trusted Publishing) and pushes the GHCR image. A PyPI
version cannot be re-uploaded once published.

```bash
git checkout main && git pull --ff-only
python -m pytest && ruff check .
# set the 0.5.1 date in CHANGELOG.md first (currently "Unreleased")
git tag -a v0.5.1 -m "schemafit v0.5.1"
git push origin v0.5.1
gh release create v0.5.1 --title "schemafit v0.5.1: README refresh and ASCII-only human output" --notes-file <body above>
```

Then check: `pip index versions schemafit` shows 0.5.1, and the README demo
output matches `uvx schemafit@0.5.1` byte for byte.
