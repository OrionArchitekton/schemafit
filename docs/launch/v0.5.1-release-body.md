A small release ahead of the Show HN post. No rule-pack changes.

### Changed
- Human-readable `lint` output uses a colon after the status
  (`[anthropic] FAIL: 2 error(s), 0 warning(s)`) instead of a long dash.
  JSON and SARIF output and exit codes are unchanged.

### Docs
- README: PyPI and GHCR install paths, a one-command `uvx` demo with real
  output, Action/pre-commit examples pinned to a real tag, and absolute links so
  the PyPI project page renders correctly.

Install: `pip install schemafit` or `uvx schemafit --help`.
Container: `docker run --rm ghcr.io/orionarchitekton/schemafit demo`.
